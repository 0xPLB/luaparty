# luaparty
Garry's mod cheat

# how to install
1. download occ (https://github.com/0xPLB/occ), and put it into ``.lje\scripts\``
2. download lje-util (https://github.com/Eyoko1/lje-util) and put it into ``.lje\scripts``
3. download lje-http (https://github.com/0xPLB/lje-http) and put it into ``.lje\scripts\``, take out the libcurl and put into ``.lje\binaries\`` folder
4. download lje-ffi (https://github.com/lj-expand/lje-ffi) and put it into ``.lje\binaries\``

# how to use
press insert twin
